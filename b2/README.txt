Aspekte B2 Study App — v0.6.0

Key updates
- Vocabulary Bank: 400 curated entries + 1,250 Discovered from book candidates, plus manual additions.
- Discovered candidates are filterable by source and remain outside Vocabulary Testing until explicitly approved.
- Vocabulary Testing uses approved/testable words only.
- Settings now includes Study display, Appearance, Desktop sidebar, Cloud sync, Backup, version and Content status.
- Final Exam is always available. 70% course progress + 20 learned words is now a readiness recommendation, not a lock.
- Existing v0.5.0 progress remains compatible.
